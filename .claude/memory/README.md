# Memoria del proyecto

Respaldo de la memoria de Claude Code para este proyecto, incluida en el repo para poder continuar en otra PC.

- `MEMORY.md` — índice de memorias.
- `taller-utesa-ia-pedagogica.md` — contexto del taller (alcance, audiencia, principios).
- `recursos-docentes-utesa.md` — contexto de la generación de recursos por materia (hallazgo de `pensum.asp`, estructura, estado).

## Restaurar en otra PC (opcional)

Claude Code lee el `CLAUDE.md` de la raíz **automáticamente**, así que el contexto esencial ya está disponible sin pasos extra.

Si además quieres usar el sistema de memoria **nativo** de Claude Code (que vive fuera del repo, en `~/.claude/projects/<hash>/memory/`), copia estos archivos a esa ruta. El `<hash>` se deriva del path del proyecto en la nueva PC; la forma simple es: abrir Claude Code en el proyecto, pedirle que guarde una memoria cualquiera (eso crea la carpeta) y luego copiar estos `.md` allí.
